# POS System (Laravel)

## Description
A simple and efficient **Point of Sale (POS) system** built with **Laravel**.  
This project allows businesses to manage sales, inventory, and customers in a streamlined way.

## Features
- User authentication and roles (admin, cashier, etc.)
- Manage products, categories, and inventory
- Process sales and generate receipts
- Track daily/weekly/monthly sales reports
- Customer management

## Technologies
- **Backend:** Laravel 10
- **Frontend:** Blade templates /  React
- **Database:** MySQL
